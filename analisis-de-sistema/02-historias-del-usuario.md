# EJERCICIO 04: Historias de Usuario

## Objetivo
Describir las principales necesidades de los usuarios del marketplace utilizando el formato:

**Como [actor], quiero [acción], para [beneficio].**

---

## 1. Cliente

| Código | Historia de usuario |
|---|---|
| **HU-01** | Como **Cliente**, quiero buscar productos, para encontrar fácilmente el producto que necesito. |
| **HU-02** | Como **Cliente**, quiero consultar la información de un producto, para conocer sus características, precio y disponibilidad antes de comprarlo. |
| **HU-03** | Como **Cliente**, quiero agregar productos al carrito, para reunir los productos que deseo comprar antes de realizar el pedido. |
| **HU-04** | Como **Cliente**, quiero realizar un pedido, para adquirir los productos seleccionados. |
| **HU-05** | Como **Cliente**, quiero efectuar el pago de mi pedido, para completar mi compra. |
| **HU-06** | Como **Cliente**, quiero consultar mis pedidos, para conocer su estado y hacer seguimiento a mis compras. |

---

## 2. Seller

| Código | Historia de usuario |
|---|---|
| **HU-07** | Como **Seller**, quiero registrar productos, para ofrecerlos a los clientes dentro del marketplace. |
| **HU-08** | Como **Seller**, quiero actualizar la información de mis productos, para mantener correctos sus datos, precios y disponibilidad. |
| **HU-09** | Como **Seller**, quiero consultar mis productos publicados, para conocer cuáles se encuentran disponibles en la plataforma. |
| **HU-10** | Como **Seller**, quiero consultar mis ventas, para llevar un control de los productos vendidos. |
| **HU-11** | Como **Seller**, quiero gestionar la información relacionada con mis ventas, para atender correctamente los pedidos realizados por los clientes. |

---

## 3. Administrador

| Código | Historia de usuario |
|---|---|
| **HU-12** | Como **Administrador**, quiero gestionar los usuarios de la plataforma, para mantener el control de las cuentas registradas. |
| **HU-13** | Como **Administrador**, quiero supervisar los productos publicados, para verificar que la información mostrada en el marketplace sea adecuada. |
| **HU-14** | Como **Administrador**, quiero administrar la información general de la plataforma, para mantener el correcto funcionamiento del marketplace. |
| **HU-15** | Como **Administrador**, quiero supervisar las actividades realizadas en la plataforma, para detectar y atender posibles problemas. |
